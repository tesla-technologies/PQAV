# Security Policy

## Reporting a Vulnerability

As this project handles post-quantum cryptography signatures (ML-DSA), we take security seriously. If you discover a security vulnerability, please report it privately. **Do not disclose it publicly** until a fix has been analyzed and released.

Please contact Toni at `security@teslatechnologies.com` with the details of the vulnerability. We will acknowledge receipt of your vulnerability report within 48-72 hours and strive to provide a timeline for the fix.
